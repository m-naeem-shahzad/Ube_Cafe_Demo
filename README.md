# Ube Coffee Co. — Complete Website Project

## Run locally in VS Code
1. Extract this ZIP.
2. Open the extracted `Ube_Coffee_Co_Final_Project` folder in VS Code (`File → Open Folder`).
3. Open `index.html` and choose **Open with Live Server**. If you do not have Live Server, open `index.html` directly in a browser.

## Important
- Keep `index.html` and the `assets` folder together in the same project folder.
- All photos and the three-bean Ube Coffee Co. logo are included locally in `assets`; no external image URLs are required.
- The Instagram section has three Instagram-style demo post cards. Likes, comments, and Follow are visual mockups; external profile links point to `instagram.com/ubecoffeeco` and should be replaced if your real handle differs.
